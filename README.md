Calculator:

Allows you to add, subtract, multiply, or divide two integers.
You can also check if numbers are even with isEven(), and you cannot divide by zero.


CalculatorTest:

Contains all the test cases for the Calculator class.
You can run these by opening IntelliJ, right clicking the test class, and clicking run 'CalculatorTest'.




DateChecker:

Checks if a month has 31 days in it.

Month enum contains all the months in the calendar.
February will always return false, since it never has 31 days.
Cannot have null input.


DateCheckerTest:

Contains all the test cases for the DateChecker class.
You can run these tests by opening IntelliJ, right clicking the test class, and clicking run 'DateCheckerTest'.
